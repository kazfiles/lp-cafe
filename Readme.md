# Cafe Bloom｜新店舗オープンLP

## 概要
架空カフェ「Cafe Bloom」の新店舗オープンを想定したランディングページです。
来店予約への導線と、世界観が伝わるデザインを意識して制作しました。

## 制作目的
- 初見ユーザーに店舗の雰囲気を伝える
- スマートフォンでも読みやすい構成にする
- 来店予約への行動を促す導線設計

## 工夫した点
- FV（ファーストビュー）では文字の可読性を重視し、画面幅に応じて改行位置を制御しています
- SCSSを使用し、セクション単位でスタイルを管理しています
- 日本語テキストが不自然に改行されないよう、`white-space` や `display` を調整しています
- ボタンは視認性とタップしやすさを意識したサイズ設計にしています

## レスポンシブ対応
- スマートフォンでは余白・文字サイズを調整
- タップしやすいボタンサイズを意識
- レイアウト崩れを防ぐため `flex-wrap` を使用
